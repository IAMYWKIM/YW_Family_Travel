## ✨ 2. 웹 앱 주요 기능

1. **모바일 반응형 탭 구조 (Single Page App):**
   * 한 손 조작에 최적화된 하단 고정 내비게이션 바 (일정 / 객실·선박 / 예산 / 체크리스트 / 유의사항).
2. **사전여행 & 크루즈 타임라인 필터:**
   * 전체 / 사전여행 / 크루즈 일정별 맞춤형 카드 필터링 제공.
   * 입·출항 시간, 선내 정찬(Dress Your Best) 및 추천 투어 동선 안내.
3. **9층 선실 시각 다이어그램:**
   * 연결문(Connecting Door)으로 이어진 **9246호(전영오·유근순) + 9248호(김용우·유근희)** 구조.
   * 엘리베이터 인접 **9162호(김기성·유근옥)** 및 복도 이동 동선(도보 2~3분) 시각화.
4. **인터랙티브 체크리스트 (로컬 자동 저장):**
   * 스마트폰 브라우저의 `localStorage`를 활용하여 체크 상태가 영구 유지됨 (진행률 % 실시간 계산).
5. **예산 및 투어 분석:**
   * Rev 0.8/0.9 기준 1인당 약 590만 원(6명 합계 약 3,185만 원) 세부 내역 및 가족별 분담액 정리.
6. **필수 출입국 및 안전 수칙 안내:**
   * 미국 ESTA 필수, 캐나다 육로/선박 입국 시 eTA 불필요 규정.
   * 선내 절대 반입금지 물품(다리미, 전기포트, 멀티탭, 육류, 과일) 안내.

## 🚀 4. 웹 호스팅 및 배포 방법

가족들이 카카오톡 링크를 눌러 스마트폰 화면에서 바로 보실 수 있도록 배포하는 방법입니다.

### 방법 A. Netlify Drop (가장 추천 - 1분 무료 배포)
1. 바탕화면에 폴더를 하나 만들고 `index.html` 파일을 넣습니다.
2. PC 브라우저로 [Netlify Drop](https://app.netlify.com/drop)에 접속하여 로그인합니다.
3. 해당 폴더를 브라우저 점선 영역에 끌어다 놓습니다 (Drag & Drop).
4. 생성된 고유 웹 주소(예: `https://alaska-family-trip.netlify.app`)를 가족 단체 카톡방에 공유합니다.

### 방법 B. GitHub Pages
1. 본 저장소의 **Settings** > **Pages** 메뉴로 이동합니다.
2. **Branch**를 `main`으로 선택하고 **Save**를 클릭합니다.
3. 잠시 후 안내되는 웹 주소(`https://<username>.github.io/<repo>/`)로 접속합니다.
